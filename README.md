# NEW-THEME-NEAN-DEV-MAR-STUDIO

Tema de Shopify basado en [Skeleton Theme](https://github.com/Shopify/skeleton-theme) v1.0.0.

## Desarrollo

```bash
shopify theme dev --store <tienda>.myshopify.com   # vista previa local con hot reload
shopify theme check                                 # lint
shopify theme push --unpublished                    # subir como tema nuevo sin publicar
```

## Estructura

`assets/` · `blocks/` · `config/` · `layout/` · `locales/` · `sections/` · `snippets/` · `templates/`
